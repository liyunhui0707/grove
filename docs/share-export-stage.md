# 实际分享导出阶段

2026-11-16完成开发和本机验收；本记录属于发布前候选，后续已随0.6.0公开，最新交付身份见build-manifest.json。日常安装另外按授权更新到已发布0.5.2，保留旧App和资料库一致备份；未打开个人照片目录。

## 行为与候选

原水印成品固定原尺寸、质量0.92，本轮仅增加原尺寸/长边2048或4096px和JPEG质量80/92/98选择。默认行为不变；保持比例、按显示方向取整数像素、不放大。预览显示该张成品尺寸，准备清单冻结参数；调整后须重新核对。每批恢复原尺寸/92%，不混入六项外观记忆。原字节复制功能未变，没有增加无水印缩图编辑器。

候选`trial-20261116T074510-8dc5b2f6eb`，channel为local-trial，版号仍0.5.2；该构建与已发布0.5.2不是同一二进制。源码摘要`8dc5b2f6eb`前缀，83项实际源文件与完整散列清单绑定。使用`npm run desktop:open`进入独立范围；日常入口是Applications中的公开0.5.2。未替换公开资产、标签或官网。

旧清单缺少新字段时使用原尺寸/92%。非默认输出参数使用format2清单；本候选可继续，新旧参数与逐项派生散列持久化。旧版只接受format1，因此明确拒绝新任务，避免静默忽略参数；不承诺把这些新任务降级到旧版继续。资料库schema未改。

- 本机macOS27.2.1 arm64原生操作三张生成12MP HEIC/JPEG出现，分别导出2048px/80%与原尺寸/92%，两批均3/3。面板重开恢复默认并清空日期城市；暗色原生截图中控件/底部动作可见，正常⌘Q退出，无测试保护结束。

## 保留的失败与限制

首次Rust套件两项系统HEIC编码被沙箱拒绝，在正常测试环境重跑通过。并行打包重写dist导致一次clippy读不到旧资源；待打包完成后单独重跑通过。以后不并行运行会消费/重写同一dist的Tauri构建与Rust检查。

原生控制曾报窗口被切换/cgWindowNotFound，重连后继续同一会话；AX直接设置日期段未产生有效日期，改用实际键盘输入并核对预览。没有把这些失败操作计为成功，也没有交回用户执行清单。ZIP的中文路径不能用Python默认名称直接定位，改用系统ditto解压后核对实际文件。

没有真实图库长期测试、新的手机样本矩阵、HDR视觉质量或30分钟负载验收。本轮不发新版；Developer ID、公证、首次浏览器隔离打开仍未验收。

实现沿用系统ImageIO，参照Apple的[缩略图最长边定义](https://developer.apple.com/documentation/imageio/kcgimagesourcethumbnailmaxpixelsize)与[JPEG编码属性](https://developer.apple.com/documentation/imageio/cgimagedestination)。没有新增依赖或改变许可。
