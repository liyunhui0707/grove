# 0.4.0 — 真实照片日常试用收口

Apple Silicon macOS 技术测试预发布；ad-hoc签名、未公证、手动更新。

- 混合目录明确显示载入照片及跳过的视频、RAW和不支持图片数量，避免将未支持格式误认为丢失。
