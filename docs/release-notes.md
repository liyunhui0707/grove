# 0.5.0 — 退出续挑与日常使用交付

Apple Silicon macOS 技术测试预发布；ad-hoc签名、未公证、手动更新。

- 同一资料目录重复启动会唤回已有窗口；可见版本、构建编号及应用/资料位置。公开版沿用日常资料目录，开发测试包保持独立。
- 记住字体、字号、颜色、透明度、边距和阴影六项水印外观，支持恢复默认与保存失败重试。新批次不带入城市和备用日期，历史批次保留自身参数。
- 正常关闭/⌘Q会等待已经发出的评分/撤销、对应的最后审片位置和样式保存。失败保留窗口，可返回、重试保存或明确放弃未保存修改后退出；不会自动重复评分或撤销。
- 改进官网中等宽度排版，并统一版本、下载、安装与升级说明。旧发行资产保留。
- SQLite继续使用schema2；升级、回退、实际安装包及原生验收范围以本版build-manifest.json为准。私人素材、路径和资料库不随产品或官网分发。

不包含视频/RAW编辑、完整Live Photo配对、真正HDR显示、跨卷移动、自动更新或其他平台支持。Developer ID／公证和浏览器隔离首次打开仍未验收。

正常退出保护不等于崩溃、断电、强制终止或文件操作中断保证。更新前备份资料库、退出旧实例并保留旧App；0.4.0不遵守新版实例互斥协议。
