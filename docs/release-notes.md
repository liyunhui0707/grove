# 0.3.0 — 手机兼容与大批照片审片测试预发布

Apple Silicon macOS；中文界面；ad-hoc签名、未公证、手动替换更新。

- macOS14+ 显式解码已验证的Apple增益图JPEG/HEIC与10位PQ HEIC，生成8位sRGB预览及水印副本。原件不变，不保留HDR显示效果；系统缺少能力时清晰拒绝。
- 修复HEIC列表尺寸为0及拍摄日期缺失；维持像素／内存限制、多帧与未知高位深拒绝。
- 复用照片名称排序器，改善大批照片筛选与排序；保持自然数字顺序、独立照片ID和七态评分。
- 本版完整自动／原生／下载与升级回退证据以同版本公开发行和build-manifest.json为准。生成HEIC不冒充手机原始HEIC；后端及JS函数指标不冒充桌面交互延迟。

Developer ID／公证仍缺少有效证书，按用户选择继续技术预发布。浏览器隔离首次打开、长期真实主库、完整Live Photo/RAW、跨卷、其他平台与自动更新仍未承诺。
