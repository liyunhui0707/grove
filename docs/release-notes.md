# 0.5.1 — 启动与评分恢复维护版

Apple Silicon macOS 技术测试预发布；ad-hoc 签名、未公证、手动更新。

- 启动时显式激活主窗口，避免已载入界面仍需手动置前才能呈现的情况。
- 启动界面独立于主模块；模块载入或首次渲染失败时显示固定错误代码和手动重试。界面首次就绪后关闭此重试入口，不会自动重载正在使用的 App。
- 增加仅在本机保存的 startup.json，保留本次及上次启动的阶段代码、版本、构建编号和耗时。没有照片、路径、异常原文或上传；记录不可写时仍可使用。原生层长时间未收到就绪信号时仅提示，不会自动退出或清空资料。
- 评分或撤销返回失败、结果不确定时暂停后续写入与退出。重新完整读取同一目录并确认相关照片后可继续，清空前端旧撤销令牌，不自动重复评分或撤销。
- 保留 0.5.0 的正常退出保存、水印样式记忆、实例互斥与续挑能力。SQLite 仍为 schema2，无资料迁移。

此前一次空白启动未能稳定复现，根因尚未确认；本版补齐恢复提示和定位证据，不声称已修复所有空白或 WebView 故障。首次提交后的运行期渲染故障不使用启动重载入口恢复。

实际安装包、原生验收与回退范围见本版 build-manifest.json。仍无 Developer ID／公证、浏览器隔离首次打开、自动更新或其他平台验收。使用前备份资料库，退出旧实例并保留旧 App。

# 0.5.0 — 退出续挑与日常使用交付

Apple Silicon macOS 技术测试预发布；ad-hoc签名、未公证、手动更新。

- 同一资料目录重复启动会唤回已有窗口；可见版本、构建编号及应用/资料位置。公开版沿用日常资料目录，开发测试包保持独立。
- 记住字体、字号、颜色、透明度、边距和阴影六项水印外观，支持恢复默认与保存失败重试。新批次不带入城市和备用日期，历史批次保留自身参数。
- 正常关闭/⌘Q会等待已经发出的评分/撤销、对应的最后审片位置和样式保存。失败保留窗口，可返回、重试保存或明确放弃未保存修改后退出；不会自动重复评分或撤销。
- 改进官网中等宽度排版，并统一版本、下载、安装与升级说明。旧发行资产保留。
- SQLite继续使用schema2；升级、回退、实际安装包及原生验收范围以本版build-manifest.json为准。私人素材、路径和资料库不随产品或官网分发。

不包含视频/RAW编辑、完整Live Photo配对、真正HDR显示、跨卷移动、自动更新或其他平台支持。Developer ID／公证和浏览器隔离首次打开仍未验收。

正常退出保护不等于崩溃、断电、强制终止或文件操作中断保证。更新前备份资料库、退出旧实例并保留旧App；0.4.0不遵守新版实例互斥协议。
