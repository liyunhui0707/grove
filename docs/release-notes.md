# 0.8.0 — 外置盘续挑与手机静态照片

技术测试预发布候选，Apple Silicon macOS；ad-hoc签名、未公证、手动更新。最终安装与交付结果以build-manifest.json为准。

- 支持提供持久卷UUID的磁盘在设备编号变化后继续关联同一文件出现；在线旧记录精确迁移，保留评分、修订号与ID。目录在扫描中离线/替换时不再误报完成。独立副本不按路径或内容合并。
- SQLite升级到schema3；首次从schema2打开前保留一致性快照。旧App拒绝schema3；回退须保留新资料并恢复升级前快照和设置，不能只替换.app。更新前完成或撤回旧文件操作，首次升级保持原照片磁盘在线。
- 识别已验证Apple Live Photo标识及同目录同名视频/RAW；单图标明静态范围，原格式复制/移动不拆分资源，补齐PEF/SRW等保护。水印可生成独立静态JPEG，关联资源保持原位；不等于完整Live Photo导出或播放。
- 三份有来源的原始HEIC/HEIF覆盖方向、日期、预览、复制与水印；缺少拍摄日期必须手填备用日期，不使用文件修改时间冒充。
- 万张生成素材后端与虚拟化验证、真实APFS镜像卸载重挂载证据分开记录，不承诺所有磁盘、系统或真实图库。
