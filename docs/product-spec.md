# 产品规格

初始确认日期：2026-11-08。本文保留产品方向，包含未实现目标；当前支持范围以 format-support.md、user-guide.md 和 current-status.md 为准。历史评估、原始需求与聊天保存在本地忽略区。

## 定位与原则

Moment Grove 是美观、简洁、开源、跨平台、本地优先的家庭影像整理应用。首先解决桌面照片浏览、筛选和精选；未来扩展视频。
优先级：美观、简洁、高效、数据安全、跨平台、本地优先、可分发、可维护。
用户无需云账号、NAS、封闭图库或手机传输工具。普通文件夹中的原件保持可访问。

## 浏览

选择本地文件夹，渐进扫描与缩略图展示；支持单图预览、缩放、上一张/下一张，按拍摄时间、名称、评分排序筛选。
支持数千至数万张照片。JPEG/PNG/WebP 为基础；HEIC 在 Spike 验证，MVP 建立明确支持矩阵。
损坏、不支持、离线、权限拒绝等状态不得被误报为空目录。

## 评分

七态：未评分、0、1、2、3、4、5。0 是淘汰候选，1–2 较低优先级，3 普通保留，4 优质，5 家庭精选/打印候选。
数字键 0–5 快速评分；另有清除评分操作。单图审片默认评分后下一张；网格批量评分不自动跳转。
评分或撤销结果未确认时暂停后续写操作，通过完整重新扫描当前目录核对实际评分；不得自动重放结果未知的写操作。失败、取消或操作目标缺失不能当作核对成功。
支持撤销、更改、筛选、批量评分和重启恢复。筛选变化时保持稳定审阅位置，防止错评、漏评、重复审阅。
SQLite 保存运行数据，XMP 提供评分迁移；App 0 映射 XMP -1，未评分映射标准未评分。不能把淘汰标记当作删除授权。

## 比较

一次 2–8 张；2/4/6/8 张有适合布局，奇数选择也自然排布。
支持活动窗格评分、同步缩放与移动、适应窗口/100%、临时查看单图细节。
不同分辨率的相对缩放与像素比例须区分。比较时不自动替换整组。手动用 [ / ] 或前/后候选只替换活动窗格，其他照片保留；候选按进入比较时的固定筛选顺序、跳过当前组且不循环。保存中与细节查看时不能替换，撤销恢复对应组与活动照片。固定参考图管理仍后置。
使用屏幕预览和按需细节加载，不默认常驻八张原始分辨率图片。

## 精选与文件操作

默认以评分和逻辑相册组织，不复制或移动原件。打印、分享时导出独立普通文件夹。
后续支持批量复制、移动、低分隔离；执行前显示不可悄悄扩大范围的清单、目标、空间、冲突和关联资源。
不得静默覆盖或永久删除。操作逐项持久化，支持取消、重试、核验及可解释恢复；不能假设整批文件操作与数据库形成原子事务。
复制需核验数量、大小和内容；恢复遇到外部修改/同名新文件时不得覆盖。
隔离和导出目录默认排除扫描。Live Photo、RAW 配对和相关 sidecar 在支持其变更前须保证不会被拆散。

## 日期与城市水印

画面内部右下角，例如“2026-10-25 温州”；不添加底部空白，不改原件。
优先 EXIF 实际拍摄时间；处理方向、HEIF 变换、时区与色彩。无日期时不得静默用复制后的修改时间冒充拍摄日期。
支持字体、字号、颜色、透明度、边距和横竖图适配；批量输出到独立目录。
后续本地候选按当前应用资料目录记住六项水印外观；城市和备用日期每个新批次清空。恢复默认只重置外观，历史清单继续使用原批参数；保存状态与失败明确显示，不把正在保存当作已保存。
第一版提供日期与手动城市，后续离线城市建议，可选在线逆地理编码；无可靠城市则只显示日期。
中国默认期望地级市名称。在线服务必须主动启用，说明位置外传与限额，不内置私人 API 密钥。
分享导出默认优先 sRGB JPEG，并提供精确 GPS 元数据处理选项。

## 架构与未来视频

一个品牌、App、仓库；模块化单体。共用目录、评分、相册、筛选、文件操作、设计系统与发布能力。
图片和视频解码、查看、处理能力分模块。视频高级功能、完整 RAW 显影、AI、人脸识别、云同步、手机传输均不在首个 Spike。
Live Photos 资源组在数据设计中预留，动态播放可后置。
独立视频产品仅在实际工作流显著分化后重新评估；不提前建设双 App 共享可写数据库。

## 发布与隐私

macOS 优先，尽早验证 Windows/Linux 构建与实际行为；未验收平台不宣称正式支持。
安装签名、公证、权限、升级迁移、许可证和干净机器验证纳入发布准备。
官网与 App 品牌统一，使用真实截图，仅提供真实可下载版本。
不得写死开发者用户名、设备或绝对路径。私人聊天和媒体不上传；公开源码在产品成熟且获得当前任务授权后进行。
