## 实现与自动验证

扫描在过程中及结束前验证固定根目录，离线或替换不误报完成。macOS 支持卷UUID的磁盘采用卷UUID、文件编号、创建时间；旧设备编号身份只在原文件在线且精确匹配时迁移，独立副本仍是独立记录。SQLite schema3 阻止旧App误读新身份；升级前通过SQLite backup API保留schema2一致性快照。

资源索引识别同目录同名视频/RAW（含PEF/SRW）与Apple Live Photo标识。静态预览有明确标签，原格式复制/移动拒绝拆分已识别资源；水印可独立派生静态JPEG。不是完整Live Photo/RAW/视频支持，被剥离的标识不能保证识别。

发布前发现并修复旧操作清单与新身份的兼容问题；两项原实现回归失败后通过，覆盖旧导出继续、移动继续/撤回、暂存文件的进程中断恢复、同字节替换文件拒绝，以及已核验成品不重写。只允许同一固定文件同时匹配旧/新身份；未迁移的旧设备编号清单在磁盘编号变化后仍保守拒绝。

最终执行：131项Rust通过、20项默认忽略，Clippy all-targets -D warnings通过。82项浏览器UI、17项逻辑、12项交付、6项官网检查及build通过；UI/逻辑来自最后兼容修复前相同前端源码。另显式运行手机原始样本、合成Live Photo标识、升级备份与APFS断线/重连试验，未将默认忽略项计入通过数。

## 本机原生证据

macOS27.2.1/arm64；10008个输入，列出10006张照片，明确跳过1视频和1RAW。10000张生成图片包含9000 JPEG、500 PNG、500 WebP，其中100张12MP，其余320×240；不能表述为万张12MP。还有三份固定提交与散列的CC BY-SA4.0原始手机HEIC/HEIF、一份合成Apple标识JPEG及两份损坏输入。来源见 [格式支持](format-support.md)。

第一候选完成0.7.0同路径升级、末尾位置/评分/设置恢复、三份手机预览、副本3/3、水印3/3。独立ImageIO核对成品尺寸、sRGB和无GPS，缺拍摄日期必须显式手填。Nokia无HDR样本在App和系统Preview方向一致，但不能据此承诺所有拍摄场景的视觉方向。损坏输入显示可解释错误并能继续浏览；资源标签及原件复制拒绝经原生确认。

自建APFS镜像实际卸载再挂载，设备编号变化；离线重扫显示未完成，重连后10006个ID及评分/修订、全部六张业务表保持。全部10008个输入的散列、大小、inode与创建时间保持。镜像试验不代表所有USB硬盘、文件系统或网络盘。

第一候选混合会话约21.9分钟，主进程及同组WebKit共262次有效footprint采样，峰值581.21MiB、结束265.02MiB；含远控等待，非活跃工作负载基准，不证明无泄漏。另完成正常退出冷重开与独立schema2快照的0.7.0原生回退；旧版回退在原设备编号可用条件下验证，不能让旧版共用schema3。

第一候选因旧清单兼容缺陷未公开，保留原始证据。含修复的最终候选补充确认同一万张资料的位置与三份手机评分、手机预览、副本1/1字节一致及正常退出。未把前候选长会话转记为新二进制重跑；最终引擎131项回归覆盖新增后端变更。
