# 日常审片、素材兼容与统一交付（0.7.0）

本轮按所有者授权合并为三个完整阶段，测试、修复与交付在阶段内完成，不要求逐项人工签核。面向Apple Silicon macOS技术试用者，沿原仓库、官网和Apache-2.0；不引入云、编辑器、其他平台或新账号。

## 审片体验

保存评分时允许先浏览下一张或替换比较活动候选；请求绑定原照片，迟到响应不将评分移到新候选。额外评分或撤销不会排队，未执行的输入持续明确显示，下一次有效操作清除提示。长按0–5、U或撤销不因系统连发重复执行。保存期间取消自动下一张立即生效。没有引入写队列或自动重放。

受控回归在回复保持未完成时已能切换候选；旧实现的两个导航用例失败，修复通过。因此消除了必须等待该次回复才能浏览的交互阻塞，不据此给出真实设备延迟百分比。撤销恢复原组与活动照片，未知写入仍须完整重读核对。整合此前已验的历史水印提示和网格最终布局恢复修复。

原生验收发现水印select的Esc会误关闭整面板，补充旧实现失败/修复通过回归；最终包展开原生下拉菜单后Esc只取消菜单，城市输入保留。编码失败说明更新，不再误称仅支持SDR HEIC。

## 失败与限制

首次沙箱全套测试中系统HEIC编码不可用；正常系统环境重跑通过。输出目录回归曾暴露对旧隔离目录规则的退化，修正后全套通过。一次新增测试准备遗漏打开面板，保留失败并修正；不计产品红测。ZIP中文文件名需按macOS编码恢复，初次检查脚本失败不代表包丢文件。

同版候选在反复替换的本地路径出现系统目录选择器“打开”禁用；取消后保留现场，新独立路径中相同最终二进制实际复制/水印通过，根因未确认。第一次最终Esc尝试未先核对弹出菜单焦点，结果不计通过；明确展开菜单后的复核通过。Git普通推送无响应，中断精确任务进程后确认远端未写入，再通过Git数据API逐个核对原始blob/tree/commit散列同步，未重写历史或强制推送。
