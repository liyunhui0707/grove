# Grove 试用指南

0.4.0：混合目录会说明已载入照片和未载入的视频／RAW／其他图片数量；筛选或搜索不会改变整目录统计。JPEG 尺寸按实际显示方向呈现。已修正部分手机 HEIC 缩略图 profile 与原图不一致造成的亮度变化；旧预览缓存会重建。


本指南适用0.10.0技术测试预发布，面向技术试用者，先用本地测试副本试用。首批包为Apple Silicon macOS；实际验收系统见随包测试报告。包声明最低macOS12，不代表每个系统版本均已测试。

## 0.10.0 Grove 与废纸篓

应用与安装入口统一为 **Grove.app**。Grove 延续原 Moment Grove 的资料目录、评分、审片位置和历史任务，不要求重新导入。新导出文件夹使用 Grove 前缀，导出清单为 `grove-export.json`；继续旧任务时保留旧名称。

进入“淘汰候选”，勾选照片或“全选当前结果”，点击“移到废纸篓”，核对照片和 XMP 清单后确认。每批 1–100 张，只接收 0 分照片，隐藏选择不能带入；评分为 0 本身不删除文件。照片会离开原文件夹，已有 XMP 一并处理；硬链接、符号链接、关联视频/RAW 或有冲突的文件不处理。失败会停止后续照片，已发生的部分操作须在“操作记录”核对，不会自动重试。

从 Finder 废纸篓找回照片及 XMP，放回原位后重新扫描；App 保留评分。⌘Z 只撤销评分，资料库快照也不能搬回照片。Grove 不提供永久删除或清空废纸篓。照片/XMP 不是原子事务，确认前仍应有独立备份。

## 0.9.0 体验改进

本节说明0.9.0的统一选择、导出和恢复流程。下文带旧版号的说明保留其历史适用范围；实际安装与测试身份见发行记录。

- 列表分别显示当前结果和整目录总数。搜索、评分筛选不会取消已有选择；底部明确提示隐藏选择数量，点“查看已选”核对全部选择，再点“返回筛选结果”。网格中的批量评分、比较、导出和移动都使用完整选择，包括隐藏项；没有选择时，导出使用当前结果。比较中的导出只含当前比较组，单图只含当前照片。
- 比较按当前排序排列所选照片。连续候选列表取进入比较时的筛选结果，并追加其中没有的已选照片；跳过当前比较组、不循环。筛选变化或评分不会悄悄扩大已经核对的导出清单。
- 顶部“导出照片”集中提供“原格式副本”和“日期城市水印”。核对照片及位置后点击“开始导出”或“生成水印照片”；完成后可直接“打开导出文件夹”或“完成”。切换导出方式会重新准备清单，每个新水印批次重新填写城市及必要的备用日期。
- “资料库工具”集中提供移动、同步、备份与重新关联。“移动与隔离”改变实际文件位置，仍须核对并明确勾选；停止会保留已完成项，恢复和撤回需重新核对。资料库备份不包含照片。评分同步针对整个目录，每页最多100项，不受网格搜索范围限制。
- 错误先显示当前问题和可采取的操作，技术原因放在“详细信息”；完整路径可以展开和复制。评分保存结果不明时暂停后续写入，重新扫描核对，不自动重放评分。位置保存失败可以单独重试。
- macOS 菜单提供打开 ⌘O、搜索 ⌘F、导出 ⌘E、水印 ⌘⇧E、重新扫描 ⌘⇧R，以及资料库和帮助入口。输入框中评分快捷键不生效，弹窗不会透传评分或主界面命令。已保存的正常退出不再闪现确认框；慢保存及失败仍保留退出保护。

保存期间仍可浏览；再次评分或撤销只提示未执行，不排队。原格式副本保留源元数据，可能包含GPS；水印生成独立sRGB JPEG，不带源EXIF/GPS。以上流程和验证边界见[整改阶段记录](experience-remediation-stage.md)。

## 安装与打开

打开DMG，将Grove.app复制到“应用程序”；也可解压zip后复制应用。退出磁盘映像，再双击安装位置的应用。运行不需要Node、Rust或开发目录。本地包为临时签名（ad-hoc），没有Developer ID签名或公证；系统可能阻止首次打开。仅在确认来源及校验和后，按系统“隐私与安全性”的允许打开提示操作；不要关闭系统保护。无法打开时保留提示反馈。

## 完成一次挑选

1. 先体验示例图库，或打开一个独立测试照片文件夹。浏览不导入或改写原图。
2. 单图用0–5评分，U清除为未评分，⌘Z撤销。0表示淘汰候选，不是删除。选择2–8张按C比较，评分只作用于活动照片。比较中用 [ / ] 或“上一候选 / 下一候选”只替换活动照片，其他窗格保留；← / →仍切换活动窗格。候选按进入比较时的搜索/筛选/排序结果前后查找、跳过当前组，不循环；保存期间可以先浏览下一张或替换活动候选，已发出的评分仍作用于原照片；细节查看时不能替换。撤销评分会恢复该次评分前的比较组和活动照片。
保存期间再次评分或撤销不会排队，界面会明确提示该次按键未执行；请确认当前照片并在保存完成后重新操作。长按评分键、U或撤销键只执行首次按下，避免系统连发误评后续照片。

3. 评分先保存在本机。看到底部“审片位置已保存”后正常退出，重开会恢复同一文件夹、上次照片、搜索/筛选/排序、网格大小与滚动位置、自动下一张和主题；无需先同步。不恢复缩放、比较布局或文件操作确认。上次照片缺失时回到列表；目录离线、权限失效或身份变化时提示重新选择，不自动匹配其他目录。
4. “评分同步”明确写入照片旁的XMP，每页最多100项；遇到外部改动先核对冲突。
5. “导出副本”原字节复制，保留原有元数据；“水印”将日期与手动城市放在照片内右下角，生成独立JPEG及评分XMP，不复制源EXIF/GPS。缺拍摄日期须填写备用日期。
6. 安全整理可移动所选测试副本，或隔离0–1分；核对清单、目标并勾选后执行。可停止、继续或核对撤回；未完成操作应先继续/撤回。外部变更或原位占用会停止，不覆盖。

## 扫描与预览恢复

0.8.0在支持持久卷身份的磁盘上保留同一卷重连后的照片身份、评分与续挑；不会按相同路径或相同内容合并独立副本。扫描中途目录离线或被替换时会报“扫描未完成”。首次从旧版升级时保持照片磁盘在线；不提供持久卷身份的文件系统会说明跨挂载限制。

单图说明会标出识别到的Live Photo标识或同名视频/RAW关联。这里只审阅静态照片，不播放完整Live Photo；原格式复制和移动暂不拆分这些资源。水印可生成独立静态JPEG，确认范围中明确说明关联文件保持原位。关联识别覆盖已验证的Apple标识和同目录同名资源，不能保证识别任意第三方改写/去除标识后的配对。

0.5.0增加水印样式记忆：字体、字号、颜色、透明度、边距与阴影自动保存在当前应用资料目录。看到“样式已保存”后关闭面板或正常退出，下一次打开会继续使用；城市和备用日期每批重新填写。“恢复默认样式”只还原外观，不清除本批日期城市；继续历史清单时使用该批原参数，不改写记住的样式。读取/保存失败有单独提示与保存重试，当前预览及导出仍可使用。浏览器演示只记住当前页面，不代表本机持久化。

0.5.0在正常关闭或⌘Q退出时，会等待已经发出的评分/撤销请求、对应的最后审片位置和水印样式保存。评分后自动下一张和撤销回到原图的位置也会一并记录；不需要先写回XMP。失败时保留窗口，可返回应用、重试保存，或明确选择“放弃未保存的修改并退出”。该选择不会显示为已保存。若评分/撤销结果尚未确认，不会自动重复执行，请返回应用检查后再决定如何处理。关闭水印面板后仍保留保护，取消退出后迟到响应不会再次退出。强制退出、崩溃、断电及文件操作中断仍按各自恢复规则处理，不在正常退出保证范围。若提示保护未启用，请重试启用，或等待各项保存状态完成后再退出。

右上角“重新扫描当前文件夹”可重新读取已经打开的目录，无需再次选择。扫描停止时只显示已找到的部分结果，底部会注明“扫描已停止”；它不代表完整目录数量。目录离线、不可读或原位置被其他文件占用时会显示“扫描未完成”，不会当作空目录。恢复磁盘或目录后重新扫描；权限不足时通过“打开文件夹”重新选择授权。真正空目录与搜索/评分筛选无结果会给出不同说明。浏览父目录时自动跳过应用生成的标准导出、水印和移动批次子目录，避免成品重复进入审片；直接打开该成品目录仍可浏览。重新扫描不清空已保存评分；未完成的安全整理仍需先继续或撤回。

预览失败可点“重试预览”。明确重试会重新解码并重建该张预览缓存，保留原图、评分及待同步项；不支持的格式仍会说明原因。浏览其他照片不需要先修复失败项。

## 资料与备份

左下角“使用说明与资料”显示本机实际资料目录及是否为隔离测试目录。默认资料目录由macOS应用数据路径提供，不在.app内。workspace.json保存最近审片位置和必要设置；它与评分分开保存，位置保存失败会单独提示。catalog.sqlite保存评分、历史和待同步队列；cache可重建；backups保存资料库快照；exports/moves保存文件操作恢复记录。照片保留在自己选择的普通目录。

用应用“资料库备份”创建一致快照。快照不含照片，不能代替照片备份；不要单独复制活动中的数据库文件。恢复快照会先备份当前资料库；有安全整理时先撤回，再恢复。恢复不会回滚已经写到外部的XMP或导出副本。

## 更新、回退与卸载

升级与回退步骤见[安装与更新](installation-upgrade.md)。本版没有自动更新。手动更新前创建资料库快照，退出所有Grove窗口并用⌘Q退出应用，保留旧.app，再复制新候选。开发候选以“使用说明与资料”里的构建编号和随包candidate.json、SHA256SUMS.txt区分，不能仅看版本号判断是否同一包。开发者本地入口为项目中的 `npm run desktop:open`，用 `npm run desktop:open -- --info`核对构建与独立资料范围；不要把裸App路径当作隔离入口。本地测试入口不会自动替换公开下载或日常安装。安装到“应用程序”后以该固定位置为日常入口，避免同时运行多份候选。

0.8.0升级到schema3并先保留schema2快照。回退0.7.0及更早版须退出新App、保留完整新资料，并在独立恢复位置使用升级前快照和设置；旧版不能直接打开schema3。具体步骤见安装说明，不修改资料版本标记或覆盖活动数据库。本阶段不承诺任意历史版本都可回退。

卸载只移走.app，不会自动删除照片、评分、快照或操作记录。不要为卸载而清理尚需恢复的资料目录。

## 当前范围

JPEG、PNG、WebP和静态 HEIC/HEIF；预览转为 sRGB，透明区域使用白底。macOS14+ 对已验证的增益图JPEG/HEIC及10位PQ HEIC显式生成SDR预览与水印。未知高位深、多帧和完整Live Photo/RAW配对仍不支持；不进行跨卷移动。支持边界见[格式说明](format-support.md)。预览失败可重试或继续查看其他照片。

当前不自动联网、查询城市、上传照片或云同步。反馈入口为 [GitHub Issues](https://github.com/liyunhui0707/grove/issues)，请先遮盖图片、日志中的个人信息。

本版在 macOS14+ 上对已验证的 HDR JPEG/HEIC 显式生成 SDR 预览和分享水印副本，保留原件但不保留 HDR 显示效果。未知高位深与多帧仍拒绝；具体样本和系统范围见格式说明。


## 启动与评分恢复（0.5.1）

启动未就绪时，界面可能显示 MG-START-MODULE、MG-START-RENDER 或 MG-START-WAIT。可先稍候，再使用“重新载入界面”或退出重开；无需清空照片、资料库或评分。界面就绪后不会再提供启动重载按钮。若原生提示 MG-START-UI 而窗口仍为空白，请保留本机资料目录，通过问题反馈提供版本和固定阶段代码，勿直接上传完整资料库。

“使用说明与资料”可查看本次启动是否就绪、记录是否保存。startup.json 仅保留本次与上次的固定阶段、版本/构建及耗时，不含照片、路径或异常原文，不上传；损坏、未来版本或不可写记录不会被强行覆盖，也不阻止审片。

评分或撤销失败后，App 会暂停相关写入。使用提示中的重新读取入口，完整读取同一目录后再继续；取消、读取失败或相关照片缺失时继续保留保护。恢复过程不会重放评分/撤销，并清除前端旧撤销历史。

## 返回照片列表（0.5.2）

从单图审片或比较按 Esc，或点击“返回照片”，会在当前筛选结果中定位刚审阅的活动照片，便于继续选择附近照片。保留原筛选和已有选择，不自动评分或重新选择照片。若当前照片因评分离开了筛选，保持该筛选，不为定位重新加入照片。定位只在返回时执行一次，此后可自由滚动；正常保存审片位置后重开保留列表位置。小窗口中照片行高超过网格时从行顶显示，不更改缩略图大小。


## 水印分享设置（0.6.0）

0.6.0增加成品尺寸和JPEG质量选择，0.5.2及更早版本不含这些新控件。先选择要带走的照片，再打开“日期城市水印”。

- 成品尺寸：原尺寸、长边2048px、长边4096px；按显示方向保持比例，短边取最近整数像素，不放大小图。
- JPEG质量：80%、92%、98%。默认为原尺寸/92%；质量值不是成品大小比例，也不是无损保证。
- 预览下方显示该张实际成品像素；确认清单显示本批参数。调整参数会作废当前确认计划，须重新选择导出位置核对。新批次恢复原尺寸/92%，日期和城市清空；外观六项记忆不受影响。
- 取消后继续保留原批尺寸与质量，逐项核验，不覆盖未知文件。旧清单缺少新字段时沿用原尺寸/92%。非默认设置使用新版操作清单，旧版App不能继续这些新任务，须使用0.6.0完成；不要以忽略参数的方式降级恢复。

成品仍是独立sRGB JPEG及评分XMP，不复制源EXIF/GPS；原件与评分不变。原字节/原元数据副本继续使用“导出副本”。本轮不增加不带水印的缩图导出、编辑器或自动更新。
