# 当前架构与开发决策

历史完整决策表保存在忽略的本地 Git 收口快照中。本文记录继续开发必须遵守的有效决策；原始 Spike 计划不是当前完成声明。

- 一个品牌、一个产品仓库、一个本地优先桌面 App；Tauri 2、React、TypeScript、Vite、Rust、SQLite。照片优先，暂不扩展云同步、AI、RAW/视频编辑或插件平台。
- 评分为 null 与 0–5 七态；0 仅是淘汰候选。SQLite 是运行目录，XMP 的未评分为缺失/0，淘汰为 -1，1–5 不变。文件出现身份不能仅依赖绝对路径或内容散列。
- 扫描与预览不改写原件。XMP 显式同步、保留未知字段并检测冲突；派生导出到独立目录。确认后的同卷整理只在明确授权副本上测试，不覆盖、永久删除或拆散未支持资源组。
- 评分/撤销结果未知时暂停后续写入，完整重读同目录后核对；不自动重放写操作。正常退出排空评分响应、最终审片位置和样式保存；失败提供返回/重试，不能宣称强退或崩溃同样保证。
- 审片位置和水印外观是独立版本化设置；不混入照片评分 schema。比较候选替换只影响活动窗格，队列稳定、撤销恢复正确目标。返回列表只在现有筛选内一次定位活动照片，不改变选择。
- 测试默认在本机，用隔离的生成或合法许可素材；远程测试须当前任务明确授权。历史其他设备证据不转记为本机通过，不要求用户逐项重复人工验收。
- 已发布版本为 0.5.2 技术测试预发布，Apache-2.0，ad-hoc 签名、未公证、手动更新。新版本号、签名渠道及再次公开交付仍须相应授权；不覆盖旧标签和资产。
- 2026-11-16：根目录接入已有公开 Git 历史，结束主目录与发布副本两套 App 源码流程。保留原 Git 元数据、文件快照和旧笔记于忽略区。使用功能分支、显式暂存和阶段提交；本地提交已获授权，推送和部署单独授权。见 [Git 工作流](git-workflow.md)。
