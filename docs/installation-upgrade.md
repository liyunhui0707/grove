# 安装、更新与回退

适用：Moment Grove 0.4.0 技术测试预发布，Apple Silicon Mac。最低系统声明为macOS12；实际验收系统与范围见发行说明。无需另装Node.js、Rust或开发环境。

## 获取与校验

仅从[本项目GitHub Releases](https://github.com/liyunhui0707/moment-grove/releases)选择确切版本和`macOS-arm64`的ZIP或DMG，并下载同一发行的`SHA256SUMS.txt`到同一文件夹。在该文件夹中执行：

```sh
shasum -a 256 --check --strict --ignore-missing SHA256SUMS.txt
```

必须看到所下载归档对应的`OK`且命令成功；没有可验证文件、散列不符或命令失败时停止，不解包、不运行。校验和能发现字节变化，但不能代替开发者签名或独立确认来源。

打开DMG，将`Moment Grove.app`复制到“应用程序”，或解压ZIP后复制该App。退出DMG，从安装位置打开；不要把磁盘映像中的App作为日常入口，也不要同时运行多份候选。左下角“使用说明与资料”显示应用版本、构建编号和资料目录。

## 签名与首次打开

本轮经用户选择继续ad-hoc测试分发；没有Developer ID签名或Apple公证。macOS可能阻止来自浏览器下载的App。这项限制没有因校验和或本机测试而消失。只在确认来源和散列后按系统提示处理；遇到无法打开的提示，保留具体信息反馈，不关闭Gatekeeper、不清除隔离属性或改系统全局安全设置。Apple官方要求Developer ID及Hardened Runtime等条件才能完成相应的[公证分发](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。

## 从0.3.0手动更新

1. 在旧App中创建“资料库备份”。快照含评分、历史和待同步项，不含照片。另有未完成安全整理时，先继续或核对撤回；不要用快照回滚代替照片撤回。
2. 用⌘Q退出所有Moment Grove实例。保留旧App副本与快照，不单独复制活动中的SQLite文件，也不删除WAL/SHM来制造可复制状态。
3. 下载并核验0.4.0，将新App放到同一安装位置。保留应用资料目录及照片目录；更新不要求清空评分、缓存或源XMP。
4. 打开新App，核对“使用说明与资料”为0.4.0及其构建编号。旧版没有续挑记录时，首次需重新选择同一个照片文件夹；已有本地候选记录时，目录身份未变则自动续挑。
5. 检查评分及待同步项，再继续评分或导出。评分先留在本机，不需要为了升级而写回源XMP。

本版仍使用内部schema2。0与未评分继续不同；新增的审片位置另存workspace.json。预览缓存可重建，不是原件或评分备份。没有自动更新、后台下载安装或静默替换功能。

## 回退与卸载

回退前⌘Q退出0.4.0，将保留的0.3.0 App恢复到原安装位置，再选择同一目录。此次支持范围仅限发行说明实际验证的0.3.0↔0.4.0/schema2组合；回退保留当前评分，回退不提供本轮新增的扫描范围说明及HEIC缩略图校正。需要回滚评分时另行使用兼容快照恢复；外部XMP、已导出副本和媒体位置不会随资料库快照自动回滚。

卸载只移走App，不会自动删除照片、应用资料、快照或恢复记录。不要为卸载清理仍需继续/撤回的操作记录。
