# 安装、升级与回退

适用：Grove 0.9.0 技术测试预发布，Apple Silicon Mac。ad-hoc 签名、未公证；手动替换应用，无自动更新。最低系统声明 macOS 12，实际验收系统与范围见发行证据。无需另装 Node.js 或 Rust。

1. 从本版 GitHub Release 下载确切的 macOS arm64 ZIP 或 DMG 及 SHA256SUMS.txt，核对完整文件校验和后解压或挂载，将 App 放到固定安装位置。
2. macOS 可能阻止未公证 App 首次打开。仅建议技术试用者使用，遵循系统提供的明确打开操作，无需关闭系统安全保护。浏览器隔离首次打开尚未验收。
3. 更新前在旧版创建“资料库备份”，完成安全整理撤回并用 ⌘Q 退出旧实例，保留旧 App。再将新版放到同一位置，保留资料目录、照片及已有 XMP。
4. 打开后在“使用说明与资料”核对 0.9.0、构建编号及资料目录。目录身份保持不变且存在已保存记录时会继续上次审片；独立测试资料不会自动合并日常评分。首次升级时保持原照片磁盘在线，才能精确迁移旧文件身份；已经离线且设备编号变化的旧记录不会按路径或内容猜测合并。

0.8.0使用SQLite schema3，防止旧App将新身份格式误当新照片。首次打开schema2资料时，先通过SQLite backup API在backups中保留一致性schema2快照，再升级；快照失败则不升级。快照仍有512MiB上限。workspace.json仍为版本1，在线旧检查点可验证后续用；水印样式另存watermark-style.json，startup.json仅作本地阶段诊断。启动失败时保留资料，不清空数据库；评分返回不确定时完整重读同目录核对，不自动重试写入。

0.7.0及更早App不能直接打开schema3资料。回退时先在0.8.0完成或撤回文件操作，保存当前资料快照并正常退出；保留整份0.8.0资料目录，在独立恢复位置使用升级前schema2快照与原设置、操作记录，再启动保留的旧App。仅替换.app不会回滚资料。不要修改user_version标记、删除记录或将旧快照裸覆盖到活动数据库/WAL上。回退会舍弃快照之后的本机评分，且不会撤回已写到外部的XMP、导出或移动。

0.6.0→0.7.0同路径升级与直接回退属于此前schema2证据，不适用于0.8.0。0.6.0非默认尺寸/质量导出使用format2清单，0.5.2及更早版不能继续。任意历史版本组合不在承诺内；0.8.0实际升级和恢复验证以build-manifest.json为准。0.4.0不遵守新版实例互斥协议，必须先退出。

卸载 App 不自动删除资料目录、照片或导出副本。需要清理时自行核对备份与所有位置，不要删除活动数据库的 WAL/SHM 文件。

0.7.0文档勘误：首发ZIP/DMG内此指南仍沿用0.6.0版号文字，实际App和构建为0.7.0；以本线上指南及发行说明为准。已发布资产和SHA-256不变，后续发行包会带入修正文档。

0.8.0 → 0.9.0 继续使用schema3及版本1审片位置，没有新增资料迁移。更新前保留旧App、一致性评分快照及设置/操作记录；完成或撤回未完成移动。只有本轮实际验证的同schema升级/回退组合属于验收范围，不能推广到任意旧版。
