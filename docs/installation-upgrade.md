# 安装、升级与回退

适用：Moment Grove 0.5.1 技术测试预发布，Apple Silicon Mac。ad-hoc 签名、未公证；手动替换应用，无自动更新。最低系统声明 macOS 12，实际验收系统与范围见发行证据。无需另装 Node.js 或 Rust。

1. 从本版 GitHub Release 下载确切的 macOS arm64 ZIP 或 DMG 及 SHA256SUMS.txt，核对完整文件校验和后解压或挂载，将 App 放到固定安装位置。
2. macOS 可能阻止未公证 App 首次打开。仅建议技术试用者使用，遵循系统提供的明确打开操作，无需关闭系统安全保护。浏览器隔离首次打开尚未验收。
3. 更新前在旧版创建“资料库备份”，完成安全整理撤回并用 ⌘Q 退出旧实例，保留旧 App。再将新版放到同一位置，保留资料目录、照片及已有 XMP。
4. 打开后在“使用说明与资料”核对 0.5.1、构建编号及资料目录。目录身份保持不变且存在已保存记录时会继续上次审片；独立测试资料不会自动合并日常评分。

SQLite 仍为 schema2，workspace.json 仍为版本1，水印样式另存 watermark-style.json。本版增加 startup.json，仅作本地阶段诊断，不迁移评分或照片。启动失败时保留资料，不要通过清空数据库尝试恢复。评分返回不确定时，按 App 提示完整重新读取同一目录后再继续，不自动重试评分写入。

回退前正常退出 0.5.1，将保留的旧 App 放回原位置。0.5.0 会忽略 startup.json，但没有本版评分异常恢复流程；不要在评分故障未核对时来回切换版本。只在发行证据实际验证的版本与 schema 组合内宣称回退通过。恢复资料库备份不会撤回外部 XMP、导出文件或媒体移动。0.4.0 不遵守新版实例互斥协议，必须先退出。

卸载 App 不自动删除资料目录、照片或导出副本。需要清理时自行核对备份与所有位置，不要删除活动数据库的 WAL/SHM 文件。
