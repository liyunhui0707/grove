# 后续推进边界

## 已完成：统一试用版交付

0.5.2已沿原仓库和官网公开为技术测试预发布，汇总返回列表定位、扫描后续挑修复及安装说明；本机完成评分/撤销、退出重开、精选导出、水印、同路径升级及0.5.1回退。公开下载散列和官网资源已核对。仍为ad-hoc、未公证、手动更新，见[构建记录](build-manifest.json)。

## 下一完整阶段：实际分享导出体验

优先依据实际照片分享时的尺寸、质量或步骤瓶颈，选择一个可复现问题改进，而不是继续增加比较能力。以“挑选→派生导出→核对尺寸/内容/原件保持”为完整闭环，由agent承担生成素材回归和必要原生检查；未测场景不变成支持承诺。新版本号和发布范围按任务授权确认，不自动发版。

## 随后：扩大公开交付能力

Developer ID/公证、浏览器隔离首次打开和升级路径仍需真实证书及对应授权。保持原仓库、官网和手动更新的事实，具备条件后集中完成一个交付阶段。其他设备格式、Intel/Windows/Linux、视频与云能力暂不扩展。

每阶段沿用[Git工作流](git-workflow.md)：从正确基线建分支，提交与证据对应，产品改动和无关工具分开；Git小提交不等于让用户逐项签核。阶段结束报告实现、实际验收范围、候选/公开身份和剩余限制，不追加逐项人工清单。
