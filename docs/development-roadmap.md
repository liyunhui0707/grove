# 后续推进边界

当前已完成返回列表定位的本地效率候选；本轮 Git 收口不新增功能、不改变版本或发布范围。

后续先依据实际试用中可复现的阻塞选一个完整阶段，包含实现、适当回归、必要原生闭环及本地提交。继续保持退出续挑、评分目标与原件安全的既有保证；不靠增加人工清单推动进度。

扩大普通用户交付仍缺 Developer ID/公证及浏览器隔离首次打开等证据；具备证书和对应授权后再推进。其他设备格式、Intel/Windows/Linux、视频与云能力不作为当前已支持承诺。

每阶段从 [Git 工作流](git-workflow.md) 开始，结束时报告提交、测试、候选与公开版本的区别。无需为了收尾自动发版。
