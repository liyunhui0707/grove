# 全流程体验整改阶段

本轮按三个工作包一次完成实现、回归、本机隔离验收及本地Git收口，不要求所有者逐项操作清单。起点为干净提交 `0d0e6c7`，产品变更提交 `d6f329c`，分支 `work/end-to-end-experience`。公开0.8.0、官网和日常Applications仍保持原交付，本轮不自动递增版本或发布。

| 工作包 | 已完成行为 | 验证重点 |

## 交付边界

最终本机入口 `npm run desktop:open`，用 `npm run desktop:open -- --info` 核对身份。候选仍为0.8.0版本号，靠独立build ID区分；资料与日常安装隔离。构建时记录提交/dirty状态，并逐项核对源清单与产品提交，后续文档提交不改变已验二进制。

本阶段没有扩大格式支持、加入连续评分队列、成组Live Photo导出、自动更新或签名公证。原生系统选择器外观由macOS决定；菜单不可用时前端拒绝命令，尚未动态灰化所有菜单项。公开发行、两台日常安装更新、浏览器隔离首次打开、其他平台及长期使用试验不属于本次完成声明。
